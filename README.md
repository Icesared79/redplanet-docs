# Red Planet Documentation

Technical documentation for Red Planet and the Atlas platform.

## What This Is

This repository is the source of truth for Red Planet's published technical documentation. Content here describes Atlas — the autonomous data and intelligence engine — and the products and operating model built on top of it. It is written for partners, prospective clients, and internal reference.

This repo is synced to GitBook. Edits land here first; the published site updates automatically.

## Structure

The documentation is organized into two tiers.

### Public Tier

Open access. Covers the problem Atlas was built to solve, what Atlas is, the data asset, and the platform model.

- The Problem
- What Atlas Is & The Intelligence Layer
- The Data Asset
- The Platform Model & Product Velocity

### Private Tier

Password protected. Covers operational internals — how the pipeline works, how Atlas heals itself, how Red Planet builds, how data quality is enforced, and the forward roadmap.

- How the Pipeline Works & Self-Correction & Healing
- The Development Model
- Data Quality, Verification & Where We're Going
